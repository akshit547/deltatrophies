Delta Trophies — Full-Stack E-Commerce & Catalogue Platform

Live site: deltatrophies.com (deployment in progress) Client: Delta Industries, Jalandhar — trophy & award manufacturer

A full-stack web platform built end-to-end for Delta Industries during a summer internship, replacing a static/legacy site with a dynamic product catalogue, admin-managed content, and lead-generation tools for distributors and B2B buyers.

✨ Features
🏆 Product catalogue — 500+ products across 10 categories (Metal, Plastic, Wooden, Acrylic, Corporate Awards, etc.), mirroring the client's official print catalogue structure
🔐 Admin panel — secure content management with JWT-based authentication + bcrypt password hashing
📦 Bulk product upload pipeline — admins can add/update large batches of products without manual entry
🎥 Factory gallery — embedded YouTube videos showcasing manufacturing
🤝 Distributor section — dealer directory with contact details
📩 Lead capture — inquiry/contact forms for B2B customers
🎞️ Smooth UI animations via Framer Motion
🔎 SEO-optimized — meta tags via React Helmet, keyword-rich product naming
🛠️ Tech Stack

Frontend

React
Tailwind CSS
Framer Motion
React Helmet (SEO)

Backend

Flask (Python)
PostgreSQL
JWT authentication + bcrypt

Deployment

Frontend: Vercel
Backend: Render
